## Inventory decisions

- **Candidates for direct initial dependencies:** FastAPI, Pydantic, SQLAlchemy, HTTPX, Uvicorn (see the PyPI evidence file); Kotlin/Android libraries remain source-only until an Android toolchain exists.
- **Architecture references only in the first increment:** Hermes Agent, LangGraph, Temporal, OpenHands, Playwright, pgvector, LiteLLM, Whisper, PEFT, Axolotl. Reference is not integration.
- **Requires additional legal/security review before adoption:** all custom, split, copyleft, `NOASSERTION`, or undetected licenses.
- **Not reused:** Claude Code; its inspected license says “All rights reserved.”
- No repository in this table has been fully vulnerability-audited merely by appearing here. Dependency scanning and exact-version review remain release gates.
