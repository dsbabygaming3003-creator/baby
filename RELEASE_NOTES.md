# Release Notes — 0.1.0 Development Increment

**Release type:** source/development preview; **not production V18**.

## Added

- Dual research deliverables: Builder AI source-backed reports and a permanent runtime GitHub Research Engine.
- Twenty-agent registry, parallel Supreme Boss tasks, dynamic factory gates and evidence.
- Model gateway with explicit mock, OpenAI-compatible HTTP/SSE, usage records and safe production mock denial.
- Skill factory, scoped memory/lexical retrieval, workflow checkpoints/resume, chat studio and real project/terminal/build APIs.
- Responsive Graphite/Cyan operations console and native Kotlin/Compose source with on-device voice route.
- Alembic migrations, owner isolation, audit/correlation, deployment reference and 14-test verification suite.

## Fixed during verification

SQLAlchemy async dependency, Pydantic model-route naming, workflow/background session handling, agent task ownership, live HTTPX OS CA trust, migration backfill and verification script path.

## Known limitations

No live hosted model account, actual translation, backend voice, production sandbox, distributed Temporal workers, vector RAG, fine-tuning, social/paper connectors, Docker/PostgreSQL verification or Android APK/install/launch. Native Android and web feature parity is incomplete. See the full acceptance matrix in `TEST_REPORT.md`.
